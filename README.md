# AI Code Review Assistant - M.Tech Project

An intelligent code review system that uses AI to analyze code quality, detect issues, and provide improvement suggestions.

## Features

- 🤖 AI-powered code analysis
- 🔍 Security vulnerability detection
- 📊 Code quality scoring
- 💡 Intelligent suggestions
- 🎨 Modern React frontend
- 🐍 Multi-language support

## Tech Stack

### Backend
- Python Flask
- Transformers (Hugging Face)
- PyTorch
- Radon, Pylint, Bandit

### Frontend
- React.js
- Material-UI
- Axios
- React Syntax Highlighter
